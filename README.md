# North Star — Backend

Backend API for North Star, a cinema information web application developed for OAMK's Advanced Web Applications Project (ID00CS47-3007).

## Tech Stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Express
- **Database:** PostgreSQL
- **Deployment:** Microsoft Azure

## Responsibilities

- Provide REST API endpoints for the frontend.
- Manage cinema and auditorium information.
- Handle database operations and request validation.
- Return consistent API responses and handle errors.

## Project Structure

The backend will follow a feature-based architecture. The folder structure will be established during application initialization.
